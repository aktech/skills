# skills

[![Checks](https://github.com/aktech/skills/actions/workflows/checks.yml/badge.svg)](https://github.com/aktech/skills/actions/workflows/checks.yml)
[![Render](https://github.com/aktech/skills/actions/workflows/render.yml/badge.svg)](https://github.com/aktech/skills/actions/workflows/render.yml)

Skills for AI coding agents.

| Skill | What it does |
|---|---|
| [launch-video](skills/launch-video) | A music-driven product launch video, rendered frame by frame at 4K 60 fps |
| [demo-video](skills/demo-video) | A narrated product walkthrough, recorded with Playwright |
| [diagrams-as-svg](skills/diagrams-as-svg) | Architecture diagrams as clean, hand-written SVG |
| [drawing-handdrawn-mermaid-diagrams](skills/drawing-handdrawn-mermaid-diagrams) | Hand-drawn Mermaid diagrams, rendered to PNG |
| [mermaid-for-excalidraw](skills/mermaid-for-excalidraw) | Readable Mermaid to paste into Excalidraw |

## Install

```sh
git clone https://github.com/aktech/skills
cp -R skills/skills/<skill> <your agent's skills folder>
```
